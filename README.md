# 🗣️ Little Voice | صوتي

A bilingual (Arabic/English) Augmentative and Alternative Communication (AAC) app designed to help non-verbal individuals and those with speech difficulties express their needs effortlessly.

> **Note:** This app was built using **Replit** during the **Startup Syria Challenge**.

---

## ✨ Key Features

- **Bilingual & RTL Support:** Seamless switching between Arabic and English with full Right-to-Left layout support.
- **Communication Board & Pain Scale:** Interactive cards with text-to-speech audio playback and a body map featuring a face-based pain scale.
- **PIN-Protected Caregiver Tools:** Secure caregiver area for personalizing photos, cards, and voice recordings.
- **Offline-First (PWA):** Installable Progressive Web App with local caching, keeping all photos and data securely saved on the user's device.

---

## 🛠️ Tech Stack & Architecture

- **Platform:** Replit
- **Technologies:** HTML5, CSS3, JavaScript (PWA Ready)
- **Storage:** Fully local storage (Local Storage / Browser Offline Caching)
